# HTML & CSS Full Course

Learn HTML and CSS from zero to advanced by building AuraMart, a responsive e-commerce website.

1. **Get the copy of the code here:**
   - [Ecommerce Project Starter (ZIP)](https://github.com/ashucodinglab/html-css-course/raw/main/ecommerce-project-starter.zip): the images and icons you need for every lesson
   - [Ecommerce Project Complete (ZIP)](https://github.com/ashucodinglab/html-css-course/raw/main/ecommerce-project-complete.zip): the finished code
2. **Get the exercises and solutions here:** [HTML and CSS Exercises and Solutions](https://ashucodinglab.com/free-resources/html-css-exercises-and-solutions/)
3. **Get the course summary here:** [HTML and CSS Course Notes](https://ashucodinglab.com/free-resources/html-css-course-notes/)

## Which folder do I need?

| Lessons | Use this from the starter |
|---|---|
| 1 to 6 | `intro-html-css/intro-images`: copy the images into your own `intro-images` folder, or use your own images |
| 7 to 19 | `auramart`: it already has the `images`, `icons` and empty `styles` folders, and we create every file together |

Stuck? Compare your code with the `ecommerce-project-complete` folder.
